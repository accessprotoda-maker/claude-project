# 工程表生成マクロ（Excel VBA版）

Pythonなしで、Excelだけで入居者一覧から住戸内工事日程表を作成するマクロです。
`tools/generate_kouji_schedule.py` と同じ内容（共用部工事日の追加、A/Bオプション表示、A4印刷設定など）をExcel VBAで再現しています。

## 使い方

1. Excelを開き、マクロ有効ブック（.xlsm）として保存する
2. `Alt + F11` でVBエディタを開く
3. メニュー「ファイル」→「ファイルのインポート」→ `GenerateKoujiSchedule.bas` を選択
4. Excelに戻り、`Alt + F8` で「GenerateKoujiSchedule」を選んで「実行」
5. 入居者一覧（.xls / .xlsx）を選択する
6. 工程表(.xlsx)の保存先・ファイル名を指定する

完成した工程表が新しいExcelファイルとして保存されます。

## 入居者一覧のフォーマット

- A列: 部屋番号
- B列: 氏名（「空室」の場合は空室として表示）
- C列: 電話
- D列: 携帯
- E列: 日程（例: `6/19（金）13:00`、`3月28日(土)9：00`）
- F列: 備考（「工期外希望」「カメラ付」「受話器」などのキーワードに対応）

1行目はタイトル、2行目は見出し、3行目以降がデータ行です。
