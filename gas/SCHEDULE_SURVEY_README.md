# 工事日程アンケート（QR・パスワード方式）プロトタイプ

各住戸ごとに固有のQRコード・パスワードを発行し、住人がスマホから工事希望日程
（第1〜第3希望）を入力できるアンケートシステムです。入力された希望は自動で
時間枠に振り分けられ、振り分けられなかった住戸は一覧で通知されます。

`GenerateKoujiSchedule.gs`（既存の入居者一覧→工程表ツール）とは別の独立した
プロトタイプです。同じスプレッドシート内に共存できます。

## できること

- 住戸ごとに固有の**QRコード**と**6桁パスワード**を発行
- 住人はQRを読み取り→パスワード入力→第1〜第3希望（日付＋時間帯）を送信
- 回答は自動でスプレッドシート（「回答」シート）に記録
- 「自動振り分けを実行」で、提出が早い住戸を優先しつつ第1→第2→第3希望の順に
  空き枠（1枠1住戸まで）を割り当て、「工程表（自動振分）」シートを生成
- 3希望すべてが他の住戸と重複して**振り分けられなかった住戸は赤字で一覧表示**
  （担当者が個別に電話等で再調整する想定）

## 導入手順

1. Googleスプレッドシートを新規作成（または既存の管理シートを利用）
2. 「住戸一覧」という名前のシートを作成し、A列に部屋番号、B列に氏名を入力する
   （1行目は見出し、2行目以降がデータ）
3. 拡張機能 > Apps Script を開く
4. `ScheduleSurvey.gs` の内容をコピーしてエディタに貼り付け、保存する
5. 同じプロジェクトに新しいHTMLファイル「SurveyForm」を作成し、
   `SurveyForm.html` の内容を貼り付けて保存する
   （ファイル名は拡張子なしで `SurveyForm` にすること）
6. 「デプロイ」>「新しいデプロイ」を選び、種類で「ウェブアプリ」を選択
   - 実行ユーザー: 自分
   - アクセスできるユーザー: 全員
   - デプロイしてURLを発行する（初回は権限承認が必要）
7. スプレッドシートを再読み込みすると「工事日程アンケート」メニューが追加される
8. 「工事日程アンケート」>「QR・パスワードを発行」を実行する
   - 「住戸一覧」シートに パスワード・トークン・回答用URL・QRコード が追加される
9. QRコードとパスワードを工事案内に印刷し、各住戸に配布する
   （QRコード画像セルを右クリック→コピーして文書に貼り付け可能）

## アンケート回収・振り分け

1. 住人がQRを読み取るとブラウザでフォームが開く
2. パスワードと第1〜第3希望（日付＋時間帯）を入力して送信
3. 回答は自動的に「回答」シートに記録される（同じ住戸が再送信した場合は
   最新の回答のみが振り分けに使われる）
4. アンケート期限後、「工事日程アンケート」>「自動振り分けを実行」を実行する
5. 「工程表（自動振分）」シートが作成される
   - 黄色: 第1希望で確定
   - オレンジ: 第2・第3希望で確定（セル内に「(第n希望)」と表示）
   - 赤字: 3希望すべて重複し振り分けられなかった住戸（要手動調整）

## 制約・注意点（プロトタイプ）

- 1つの時間枠（日付×時間帯）に工事できるのは1住戸までという前提です。
  複数戸が同時に工事可能な場合は `ScheduleSurvey.gs` の振り分けロジック
  （`allocateSurveySchedule`）の容量判定を拡張してください。
- 振り分けは「回答が早い住戸を優先」する単純な早い者勝ち方式です。
  公平性のルール（抽選・部屋番号順など）が必要な場合はロジックの変更が必要です。
- QRコードの生成には外部サービス（api.qrserver.com）を利用しています。
  社内ネットワークの制約等で利用できない場合は、別のQR生成方法に置き換えてください。
- 既存の「工程表」（住戸内工事日程表）と書式を合わせたい場合は、
  `writeAllocationResult_` の出力部分を `GenerateKoujiSchedule.gs` の
  レイアウトに合わせて調整してください。
